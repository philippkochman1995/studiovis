# Studio Vis – lokale Website

Die Website kann direkt über `index.html` im Browser geöffnet werden. Der Button „Weiter“ führt zur Auswahlfrage. Die erste Antwort öffnet die Website-Projekte, die zweite das Google-Rezensionsformular von Studio Vis. Von den Website-Projekten führt „Weiter“ zur Kontaktseite. Die Projektbelege öffnen mit der lokal eingebundenen GLightbox-Bibliothek.

Alternativ im Ordner `Website` starten:

```sh
python3 -m http.server 8080
```

Danach `http://localhost:8080/` aufrufen.
